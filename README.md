# Autonomous Vehicle Motion Planning & MPC

A model-based autonomous driving project focusing on the pipeline from **path planning and trajectory generation to model predictive control (MPC)** for vehicle trajectory tracking.

> **Project status:** In development  
> Quantitative results will be added after the implementation and experiments are completed.

## 1. Motivation

Autonomous driving requires more than high-level behavioral decisions. A planned maneuver must be converted into a dynamically feasible trajectory and then tracked by the vehicle controller.

This project studies a modular pipeline:

```text
Road / Reference Path
        ↓
Path Planning
        ↓
Frenet-Based Trajectory Generation
        ↓
Vehicle Model
        ↓
Model Predictive Control (MPC)
        ↓
Vehicle Motion
        ↓
Trajectory Tracking Evaluation
```

The main objective is to understand the interaction between **motion planning, vehicle dynamics, and constrained control**.

## 2. Problem Definition

The ego vehicle is required to follow a reference path or trajectory while satisfying vehicle and control constraints.

The project focuses on:

- path representation
- trajectory generation
- vehicle motion modeling
- constrained trajectory tracking
- quantitative controller evaluation

## 3. Planning Layer

### Frenet Coordinate System

The reference road is represented using a curvilinear Frenet frame:

```text
Reference path
      ↓
Cartesian position (x, y)
      ↓
Frenet coordinates (s, d)
```

where:

- `s` represents longitudinal progress along the reference path
- `d` represents lateral offset from the reference path

Candidate trajectories can then be generated by planning longitudinal and lateral motion in the Frenet frame.

## 4. Vehicle Model

The initial implementation uses a simplified vehicle model suitable for trajectory tracking experiments.

Depending on the final experiment setup, the model may include:

- longitudinal velocity
- vehicle position
- heading angle
- steering input
- acceleration input

A kinematic bicycle model is used as the initial baseline, with higher-fidelity dynamics added only when necessary for the research question.

## 5. MPC Formulation

At each control step, MPC predicts future vehicle motion and solves a constrained optimization problem.

Conceptually:

```text
Current Vehicle State
        ↓
Prediction Model
        ↓
Future State Prediction
        ↓
Optimization
        ↓
Optimal Control Sequence
        ↓
First Control Input
        ↓
Vehicle
        ↺
```

The optimization objective will penalize quantities such as:

- lateral tracking error
- longitudinal tracking error
- heading error
- control effort
- excessive control variation

Subject to:

- vehicle-state constraints
- steering constraints
- acceleration / deceleration constraints

## 6. Experimental Plan

### Experiment A — Basic Trajectory Tracking

Test whether MPC can follow reference trajectories under nominal conditions.

Metrics:

- lateral RMSE
- longitudinal RMSE
- heading error
- maximum tracking error

### Experiment B — Different Driving Conditions

Evaluate the controller under different:

- vehicle speeds
- road curvatures
- trajectory shapes

The goal is to identify conditions under which tracking performance changes significantly.

### Experiment C — Parameter Sensitivity

Study the influence of:

- prediction horizon
- control horizon
- state cost weights
- control input weights

The final report will document the selected parameters and their effects.

### Experiment D — Constraint Handling

Evaluate whether the controller respects predefined:

- steering limits
- acceleration limits
- state constraints

Constraint violations will be explicitly recorded rather than inferred from tracking performance alone.

## 11. Key Questions

This project investigates:

- How does Frenet-based trajectory generation simplify vehicle motion planning?
- How does MPC perform under different road curvatures and vehicle speeds?
- Which MPC parameters have the strongest influence on tracking performance?
- How do vehicle and control constraints affect trajectory tracking?

## 12. Limitations

This is a simulation-oriented project and does not represent the full autonomous driving stack.

The current scope does not include:

- perception
- localization from real sensors
- HD maps
- full traffic prediction
- real-time vehicle hardware
- real-vehicle validation

The focus is specifically on **motion planning, vehicle modeling, and model-based control**.
